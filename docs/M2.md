## 4. decide 流水线

```
Context → gates（顺序：enabled → explicit direction → do-not-interrupt →
          daily cap → min interval → same topic → consult throttle → legacy dice）
        → judge(ctx) 桩/宿主模型 → parse_decision + parse_needs_tools
        → Outcome.action:
             dropped（闸门/判否/invalid JSON）
             sent（allow 且有文本）
             handoff（needs_tools 且 directed → 交回主 agent）
             tool_task（needs_tools 且非定向 → 后台工具任务）
             candidate（未接 judge 的纯闸门模式）
```

- **定向路径跳过全部 ambient 闸 + consult 节流**（与生产 `_maybe_group_interject` 的 `if not directed:` 一致；定向 fast-path 开关本身属 adapter 配置）。
- 显式 `gates=[...]` 由调用方负责（可覆盖默认行为），文档已注明。
- 闸门不原地改 group dict；`interject_today`、`consult_at` 等状态由调用方传入/落盘。

## 5. 行为差异 / 留给 adapter

1. 预算函数接收**已过滤**的 `recent_messages`（生产的 `_filtered_group_recent_messages` 属宿主）。
2. `link_payload` 闸、atmosphere/pace/rhythm 权重、方向权重乘子仍留 adapter（M2 保留确定性硬闸 + 软闸 weight；legacy 骰子路径是简化版，见第 10 条）。
3. 判据模板是**通用决策契约**，不是 326KB 插件里的人设/玩梗 prompt；prompt 热改/AB 留 M3。
4. `needs_tools` 的定向判定用 `Context.directed/scene_trigger`，不读 IM 事件。
5. 回放集 9 条是**合成/示意用例**（raw JSON 代模型，满足 M2 桩回放）；真实生产判定的离线回放集留 M3。
5. ShadowBook 不落盘；`reviewers` 只返回 flags，是否重写回复由宿主决定（影子期默认不升级）。
6. **SameTopic 默认签名是 sha1(文本)**，生产是语义分类 `_proactive_topic_signature`；adapter 必须注入生产签名。
7. **DailyCap 未建模 effective 限额**（intensity / `_PROACTIVE_DAILY_LIMIT_UNLIMITED`）且 `_day_key` 用本地时区；adapter 需按宿主时区/effective 值接。
8. **闸顺序/多闸失败 reason 优先级**与生产不逐一相同（allow 结果一致）；`decide(gates=...)` 不替调用方做定向过滤。
9. `default_gates()` 每次新建 consult store；要跨消息节流，adapter 必须持有同一个 store / `ConsultThrottleGate` 实例（已加 `throttle_store=` 参数）。
10. LegacyDiceGate 是简化版（保留概率/稳定骰/预算乘子，未复刻 pace/rhythm/direction 全权重）；回退骰子路径以 adapter 为准。
11. `parse_decision` 是生产行为的**超集**：额外接受已解析 dict；`turn_had_retrieval` 用 `event_present=` 表达生产"有事件但无工具属性→False"。
