## 3. CLI 速查

```bash
PY=/root/AstrBot/.venv/bin/python
cd /sdcard/dsh-work/memorix

# 只读诊断（默认）
PYTHONPATH=src $PY -m memorix diagnose --db <DB> [--state <state.json>] [--ledger <ledger.md>] \
  [--audit-snapshot <snap.json>] [--config '<glob>'] [--json] [--strict]
PYTHONPATH=src $PY -m memorix orphan  --db <DB> --state <state.json>
PYTHONPATH=src $PY -m memorix status  --db <DB> --state <state.json> [--apply]
PYTHONPATH=src $PY -m memorix audit   --ledger <ledger.md> --config '<glob>' [--audit-snapshot <snap.json>] [--apply]
PYTHONPATH=src $PY -m memorix intents --db <DB> [--apply]
PYTHONPATH=src $PY -m memorix decay   --db <DB> [--apply]
PYTHONPATH=src $PY -m memorix finish  --db <DB> --state <state.json> --ledger <ledger.md> \
  --user-end N --bot-end N --mem-ids "1,2|none" --ledger-mark "标题|none" [--apply]
PYTHONPATH=src $PY -m memorix consolidate --db <DB> --show
PYTHONPATH=src $PY -m memorix consolidate --db <DB> --apply-file plan.json [--apply]
```

- `--apply` 写库前自动 `backup_database()` 到 `<db>/../memorix-backups/`；写 state 前备份旧 state。
- `finish` 被拒时 exit 3（与生产一致：游标不动）；库/配置错误 exit 4；`--strict` 有 HIGH 时 exit 1。
- `consolidate --show` 只输出最近 5 条 episodic 给 LLM；`--apply-file` 只接受通过
  `validate_plan()` 的计划（窗口内、episodic、重算 importance），**不在代码里猜主题**。
