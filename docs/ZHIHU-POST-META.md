## 短版“想法”

> 长期 Agent 的记忆问题，通常不是“存不下”，而是三件事没分开：记忆库会脏（孤儿/衰减/过期意图）、召回会注错（无锚契约被词面顶进来）、接话没边界（该不该说和知不知道是两回事）。
>
> 我把这三件事抽成了一个零依赖 Python 内核 MemPatrol：默认只读、`--apply` 先快照、任意 SQLite schema、CLI + 只读 MCP。默认 lexical，vector 只留 provider 接口，不吹语义。
>
> 项目很新，欢迎拿你的库结构来拍砖：https://github.com/yikoko01/mem-patrol
