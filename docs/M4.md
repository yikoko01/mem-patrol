## 1. 最优配置选择（明确记录）

| 项 | 选择 | 理由 |
|---|---|---|
| 运行时 | 纯 stdlib，零第三方依赖 | 与 M0–M3 一致；`npx`/pip 安装都不拉依赖树 |
| MCP 传输/协议 | stdio + JSON-RPC 2.0；协商 `2025-06-18` / `2025-03-26` / `2024-11-05` | 兼容新旧客户端；不引 MCP SDK |
| MCP 权限 | 只读工具（无 apply/写） | 修复动作留在 CLI 的 `--apply` + 自动备份里 |
| 打包 | `pyproject.toml`（setuptools）+ `mem-patrol` 发行名；console scripts `memorix`/`memorix-mcp` + `mem-patrol`/`mem-patrol-mcp` 别名 | 一个 wheel 同时给 CLI 与 MCP |
| 许可 | Apache-2.0 + `LICENSE`（PEP 639 license expression） | 与决策 #5 一致 |
| 可选依赖 | `.[anchor]`=jieba；`.[test]`=pytest+jieba | 运行零依赖，测试/锚定可选 |
| CI | GitHub Actions：3.10/3.11/3.12 测试 + bench + eval + wheel 构建/安装 | 发布前全链路 |
| Release | tag `v*` 触发 build + 安装验证 + GitHub Release artifacts | release workflow 可复现（未触发） |
